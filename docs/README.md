# Documentation

Start with [your first workflow](guides/getting-started.md). Operators install
with the [single-server runbook](operations/single-server.md), then use
[upgrading](operations/upgrading.md). Single-server self-hosting is the only
supported deployment; AWS/ECS hosting proposals are historical and unsupported.

- [Decisions](adr/README.md): active rules and historical rationale.
- [Feature plans](feature-plans/README.md): scoped work and delivery history.
- [Repository instructions](../AGENTS.md) and [naming](naming.md).
