# Show public form links again

With connection encryption configured, editors can retrieve a public form link without rotating it. Store an existing connection envelope in one nullable workflow_forms.sealed_capability jsonb column; allow legacy hash-only rows and forbid sealed copies without a hash. API setAccess seals with the existing connection encryption runtime, bound to workspace and workflow. Core writes and clears both fields atomically. Without the optional connection encryption runtime, public writes retain a digest only and the API returns the capability once in the command response, never its stored receipt. GET access returns no capability; if a sealed copy exists without an available runtime it logs an operator warning and preserves the copy and working public link. The UI retains a command-issued capability only for its current revision until the view closes. GET access returns plaintext only with workflow:update folder permission. Receipts and audit facts retain metadata only. Retained-key preflight for deployment, restoration and worker startup includes sealed form capabilities with their workflow-bound connection context, so form-only missing or wrong keys refuse preflight. Legacy links keep working and explain the one-time regeneration. Web shows copy and QR controls and confirms that regeneration breaks posted pages and QR codes.
