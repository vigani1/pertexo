# Failure-path review images

Synthetic mocked-browser fixtures, captured at 1440 × 900 and 375 × 768 for
editor authoring, and 1280 × 768 and 375 × 768 for handled history. The phone
cases use reduced motion and keyboard-accessible controls. Before/after compares
Stop run on failure with the same draft after adding its separate handler.

The history images keep the failed source and its failed attempt visible beside
the successful handler and the “Finished — 1 failure handled” headline. Missing
recorded input remains missing; it is never synthesized from failure evidence.

These images contain no live credentials, cookies or owner data. The actual
browser/API/database/worker scenario is verified separately; its traces and
screenshots remain disabled.
